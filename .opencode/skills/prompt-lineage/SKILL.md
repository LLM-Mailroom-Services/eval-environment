# Prompt lineage (mailroom-dataset-v1)

The frozen v1 snapshot is the OFFICIAL prompt version 1 and the default for
every eval run. Never edit `src/evals/prompts/frozen_v1.py` or
`prompts/*.md` by hand.

## Layers & resolution

`evals.prompts.lineage.resolve(key)` — frozen → mutation → archived → production;
frozen wins ties; unknown keys raise.

- **frozen** `*_v1` — generated by `scripts/freeze_prompts.py` / sandbox
  promotion. Extraction specialists are the concise sandbox prompts; other
  roles stay the production freeze. 14 keys; see `prompts/manifest.json`.
- **archived** `*_v0` — the pre-concise production specialist freeze
  (`archived_production.py` + `prompts/archive/`). Opt-in only.
- **mutation** — appended ONLY via `evals.prompts.mutations.apply_mutation`
  (persists to `prompts/mutations.json`); keys are `<role>_v<N+1>`.
- **production** — the pipeline package's own templates
  (`llm.prompts.prompt_templates`).

## Runtime injection (two choke points)

`evals.prompts.registry.activate(source, overrides)` patches:

1. `llm.prompts.get_managed_prompt` (BaseAgent prompts)
2. `langchain_agents.prompts.PROMPT_VERSIONS` (LangChain versioned keys)

The runner activates before any agent instantiation and deactivates in its
`finally`. Works for real runs: with Braintrust/Phoenix as provider,
`get_managed_prompt` resolves the local fallback path that activate patched.

## Provenance per run

`prompt_lineage`, `prompt_source`, `prompt_versions` (per-agent
key/lineage/sha256), `pipeline_git` (llm-mailroom commit), and
`prompts_snapshot.json` in the run dir (exact rendered texts).

## GEPA mutation gates (evals.prompts.mutations)

1. ANCHOR — occurs exactly once in the parent text
2. KEY — unused + `<role>_v<parent.version+1>` naming
3. ADDITIVE — parent preserved outside the anchor span
4. METADATA — parent + change note recorded

One rule per mutation, one A/B per mutation, same subset/seed. The OBSERVE
input is `score_run.py --export-failures`. Judge rubrics for post-hoc scoring
come from the frozen keys (`judge_v1`, `judge-classification_v1`,
`judge-correctness_v1`, `pipeline_verdict_v1`, `pipeline_quality_v1`).
